## О репозитории

**CPlusPlusMiniProjects** — учебный репозиторий, в котором я закрепляю изученные темы C++ через самостоятельную разработку небольших консольных приложений.

Проекты постепенно усложняются: от программ с условиями и циклами до приложений с функциями, массивами, строками, двумерными массивами и организацией состояния программы.

Главная цель — не просто получить работающий результат, а научиться самостоятельно проектировать алгоритмы, разбивать задачу на логические части и улучшать качество кода.

## Сборка и запуск

Для компиляции отдельного исходного файла из корня репозитория используй GCC:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic "MatrixAnalyzer.cpp" -o MatrixAnalyzer
./MatrixAnalyzer
```

Замени имя файла на нужный исходник. Кавычки полезны для имён файлов, содержащих пробелы. Если программа состоит из нескольких исходных файлов, передай компилятору все необходимые файлы.

Параметры компиляции:

- `-std=c++20` — использовать стандарт C++20.
- `-Wall -Wextra -Wpedantic` — включить дополнительные предупреждения компилятора.

Сборка создаёт исполняемый файл. Его не следует считать исходным материалом проекта или добавлять в Git без необходимости.

## Подход к обучению

Для каждой темы я стараюсь пройти путь от понимания концепции до самостоятельного применения:

```text
Теория
   ↓
Практические задачи
   ↓
Закрепление предыдущих тем
   ↓
Мини-проект
   ↓
Отладка и проверка
   ↓
Рефакторинг
```

Новые возможности добавляются постепенно, с опорой на уже изученный материал. По мере роста сложности я уделяю больше внимания структуре программы, понятным именам, повторному использованию функций и корректной работе с данными.

## Направление развития

Дальнейшая практика будет расширяться вместе с обучением C++: стандартная библиотека, контейнеры и алгоритмы, файловые операции, классы и инкапсуляция, RAII и управление ресурсами, шаблоны, обработка ошибок и более крупные приложения.

Это направления дальнейшего развития, а не заявление о полном освоении всех перечисленных тем.
