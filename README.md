## 📖 О проекте

**C++ Мини-проекты** — это коллекция небольших консольных приложений, созданных в процессе изучения и практики C++.

Репозиторий построен как последовательное развитие навыков:

```text
Основы программирования
        ↓
Условия и логика
        ↓
Циклы
        ↓
Функции
        ↓
Массивы и строки
        ↓
STL
        ↓
Работа с файлами
        ↓
Объектно-ориентированное программирование
        ↓
Более крупные приложения
```

Основная цель — перейти от решения отдельных учебных задач к способности **самостоятельно проектировать и реализовывать полноценные программы**.

# 🏦 Текущие проекты

## ATM

Консольная симуляция банкомата, поддерживающая несколько операций:

* просмотр баланса;
* пополнение счёта;
* снятие денег;
* перевод денег;
* расчёт комиссии;
* проверка корректности суммы;
* проверка достаточности средств.

Проект демонстрирует переход от последовательного кода к **разделению логики программы на отдельные переиспользуемые функции**.

Пример функций:

```cpp
void printMenu();

double inputAmount();

double calculateCommission(double amount);

bool canWithdraw(double balance, double amount);

double deposit(double balance, double amount);

double withdraw(double balance, double amount);

double transfer(double balance, double amount);
```

# 🧠 Принципы разработки

Проекты развиваются по нескольким принципам.

### 1. Сначала понимание — потом абстракция

Сложные абстракции вводятся только после понимания базовых принципов программирования.

### 2. Небольшие, но законченные проекты

Проект должен быть достаточно маленьким для полного понимания, но достаточно полноценным, чтобы вести себя как реальная программа.

### 3. Рефакторинг — часть обучения

Старые проекты будут постепенно улучшаться по мере получения новых знаний.

Например:

```text
Первая реализация
       ↓
Рабочая программа
       ↓
Рефакторинг
       ↓
Улучшение функций
       ↓
Улучшение структуры
       ↓
Более чистая архитектура
```

### 4. Постепенное увеличение сложности

Каждый следующий проект добавляет ограниченное количество новых концепций.

Это позволяет сосредоточиться на понимании материала, а не просто на получении работающего кода.

# ▶️ Сборка и запуск

Клонирование репозитория:

```bash
git clone https://github.com/Denisov-Egor/CPlusPlusMiniProjects.git
cd CPlusPlusMiniProjects
```

Компиляция проекта:

```bash
g++ -std=c++17 ATM.cpp -o ATM
```

Запуск:

```bash
./ATM
```

Для других проектов используется аналогичная схема:

```bash
g++ -std=c++17 ProjectName.cpp -o ProjectName
./ProjectName
```

```text

        ↓
```

Именно этот прогресс является основной целью репозитория.
