## О репозитории

**CPlusPlusMiniProjects** — коллекция самостоятельных учебных проектов, которые постепенно усложняются вместе с изучением C++.

В репозитории есть приложения для работы с числами и массивами, финансовыми расчётами, покупками, игровыми персонажами, расследованием дела и учётом складских запасов. В проектах я практикую декомпозицию задач на функции, работу с состоянием программы, массивами, строками, указателями и динамической памятью.

## Изучаемые темы

Проекты отражают практику следующих тем:

- Базовый синтаксис C++, типы данных, ввод и вывод.
- Условные конструкции, `switch` и циклы.
- Функции и декомпозиция программы.
- Одномерные и двумерные массивы.
- Строки и `std::string`.
- Ссылки и указатели.
- Динамическое выделение и освобождение памяти.
- Поиск, подсчёт, агрегирование и анализ данных.
- Работа с меню и состоянием консольного приложения.
- Основы моделирования предметной области на примерах магазина, финансов, расследования и склада.

Темы применяются в разных сочетаниях: не каждый проект использует все перечисленные возможности.

## Сборка и запуск

Исходные файлы находятся в корне репозитория. Для компиляции выбери нужный файл и используй GCC:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic "WarehouseInventoryManager.cpp" -o WarehouseInventoryManager
./WarehouseInventoryManager
```

Чтобы собрать проект с именем файла, содержащим пробелы:

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic "Player Manager.cpp" -o "Player Manager"
./"Player Manager"
```

Для остальных проектов замени имя исходного файла и имя исполняемого файла. Каждый проект содержит собственную функцию `main()`, поэтому проекты следует компилировать и запускать **по отдельности**, а не собирать все `.cpp` в одну программу.

Параметры компиляции:

- `-std=c++20` — использовать стандарт C++20.
- `-Wall -Wextra -Wpedantic` — включить дополнительные предупреждения компилятора.

Исполняемые файлы — результаты сборки, а не исходный код проектов.

## Подход к обучению

Мой подход — самостоятельно разбираться в теме и закреплять её на практических задачах:

```text
Теория
   ↓
Практические задачи
   ↓
Использование ранее изученных тем
   ↓
Мини-проект
   ↓
Проверка и отладка
   ↓
Улучшение структуры кода
```

По мере усложнения проектов я уделяю внимание разделению программы на функции, понятным именам, проверке пользовательского ввода и корректной работе с данными и памятью.
