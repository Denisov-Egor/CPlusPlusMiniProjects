## О репозитории

**CPlusPlusMiniProjects** — коллекция самостоятельных учебных проектов, созданных в процессе изучения C++.

Каждый проект представляет собой небольшое консольное приложение с собственной задачей и набором возможностей. Сложность постепенно увеличивается: от простых вычислений и анализа массивов до приложений с управлением данными, динамической памятью и моделированием предметных областей.

Основная цель — закреплять теорию на практике, учиться самостоятельно проектировать решения и писать понятный, структурированный код.

## Изучаемые темы

Проекты объединяют практику нескольких направлений C++:

- **Основы языка:** типы данных, переменные, ввод и вывод.
- **Управление выполнением:** условия, `switch` и циклы.
- **Функции:** декомпозиция программы и передача данных.
- **Массивы:** одномерные и двумерные массивы.
- **Строки:** работа с `std::string`.
- **Указатели и ссылки:** передача данных и работа с адресами.
- **Динамическая память:** выделение и освобождение памяти.
- **Алгоритмическая практика:** поиск, сортировка, подсчёт и анализ данных.
- **Проектирование приложений:** меню, состояние программы и моделирование предметных областей.

Не каждый проект использует все перечисленные механизмы. Набор тем зависит от его задачи и сложности.

## Сборка и запуск

Для компиляции используется GCC с поддержкой C++20.

Исходные файлы расположены в корне репозитория. Каждый проект содержит собственную функцию `main()`, поэтому их необходимо собирать и запускать отдельно.

**Пример: Warehouse Inventory Manager**

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic \
    WarehouseInventoryManager.cpp \
    -o WarehouseInventoryManager

./WarehouseInventoryManager
```

**Пример: Player Manager**

```bash
g++ -std=c++20 -Wall -Wextra -Wpedantic \
    "Player Manager.cpp" \
    -o "Player Manager"

./"Player Manager"
```

Для сборки другого проекта замени имя исходного файла и имя исполняемого файла.

| Параметр     | Назначение                          |
| ------------ | ----------------------------------- |
| `-std=c++20` | Использование стандарта C++20       |
| `-Wall`      | Основные предупреждения компилятора |
| `-Wextra`    | Дополнительные предупреждения       |
| `-Wpedantic` | Проверка соответствия стандарту     |

## Подход к разработке

Каждый проект — возможность не только применить изученную тему, но и улучшить навыки разработки.

Мой рабочий процесс:

```text
Изучение темы
      ↓
Самостоятельное решение задач
      ↓
Проектирование решения
      ↓
Реализация приложения
      ↓
Проверка и отладка
      ↓
Анализ и улучшение кода
```

При разработке уделяю внимание:

- разделению ответственности между функциями;
- понятной структуре программы;
- читаемости и простоте кода;
- корректной обработке пользовательского ввода;
- правильной работе с данными и памятью;
- поиску и устранению избыточных операций.

## Дальнейшее развитие

По мере изучения C++ планирую постепенно усложнять проекты и применять новые возможности языка.

Основные направления дальнейшей практики:

- классы и инкапсуляция;
- конструкторы и деструкторы;
- RAII и управление ресурсами;
- стандартная библиотека и контейнеры;
- файловые операции;
- обработка ошибок;
- шаблоны;
- более крупные консольные приложения.

Это направления дальнейшего развития репозитория, а не утверждение, что все перечисленные темы уже освоены.
