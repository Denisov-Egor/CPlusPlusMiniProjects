## 📖 О проекте

Этот репозиторий содержит серию учебных мини-проектов на **C++**, разработанных для последовательного изучения языка через практику.

Основная цель — не просто изучить синтаксис C++, а научиться превращать изученные конструкции языка в работающие программы с понятной структурой и логикой.

Проекты расположены по мере усложнения и позволяют постепенно перейти от базовых конструкций к более структурированным приложениям.

# 🏦 Что демонстрируют проекты

## 🏧 ATM

**ATM** — консольный симулятор банкомата.

Программа позволяет выполнять основные операции:

* просмотр баланса;
* пополнение счёта;
* снятие денежных средств;
* перевод;
* расчёт комиссии;
* проверку достаточности средств;
* взаимодействие с программой через меню.

### Что демонстрирует

Проект показывает переход от простых последовательных инструкций к более структурированной процедурной программе.

Используются:

* `switch` для организации меню;
* `while` для постоянного взаимодействия с пользователем;
* функции для разделения программы на отдельные операции;
* параметры функций;
* возвращаемые значения;
* `bool` для логических проверок;
* `if/else` для реализации бизнес-логики;
* обработка пользовательского ввода;
* хранение и изменение состояния программы;
* последовательность проверок перед выполнением операции.

### Учебный акцент

**Переход от простого процедурного кода к декомпозиции программы на отдельные функции.**

Проект предназначен для практики базовой алгоритмики и работы с числовыми данными.

### Что демонстрирует

Проект закрепляет:

* числовые типы данных;
* арифметические операции;
* сравнение значений;
* `if / else`;
* циклы;
* логические операторы;
* пользовательский ввод;
* последовательную обработку данных;
* построение алгоритма из набора условий;
* поиск нужного результата среди нескольких значений.

### Учебный акцент

**Развитие алгоритмического мышления и понимание того, как из простых условий строится полноценный алгоритм.**

# 🧠 Принципы разработки

В процессе разработки проектов используются следующие принципы:

### 1. Практика после теории

Каждая изученная конструкция должна закрепляться написанием собственного кода.

### 2. Постепенное усложнение

Каждый следующий проект должен добавлять новые концепции поверх уже изученных.

### 3. Понятная структура

Код должен быть разделён на логические части, а повторяющиеся операции — выноситься в функции.

### 4. Минимум лишней сложности

На начальном этапе используются только те конструкции, которые уже изучены.

### 5. Самостоятельное решение

Перед использованием готового решения задача сначала разбирается самостоятельно.

### 6. Рефакторинг

После завершения проекта код анализируется и постепенно улучшается.

# ▶️ Сборка и запуск

Для компиляции отдельного проекта можно использовать `g++`.

Например:

```bash
g++ ATM.cpp -o ATM
```

Запуск:

```bash
./ATM
```

Для другого проекта:

```bash
g++ NumberAnalyzer.cpp -o NumberAnalyzer
./NumberAnalyzer
```

Аналогичным образом можно собрать остальные `.cpp` файлы.

# 🔬 Подход к обучению

Обучение строится по циклу:

```text
Теория
   ↓
Небольшая задача
   ↓
Практика
   ↓
Мини-проект
   ↓
Ошибки и отладка
   ↓
Рефакторинг
   ↓
Следующая тема
```

Главная задача — не просто получить работающий код, а понять:

**почему программа работает, как построен алгоритм и почему код организован именно таким образом.**
